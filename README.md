This repo houses my attempts to learn Lua, in combination with C.

Given how Lua is written with ANSI C in mind,
every C file in this project will be written in ANSI C.

---

I'm using Lua 5.4.7 and have imported it into the project.

Two source files are actually programs (`lua.c` and `luac.c`),
have `int main`, and don't have to be compiled.
They have been renamed so that their original names have
`.nocompile` appended to them.
